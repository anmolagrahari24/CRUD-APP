# CRUD Application

A simple **CRUD Application** designed to manage records efficiently with an easy-to-use and responsive interface.

## 📌 About the Project

This project demonstrates the implementation of the four basic operations of data management:

**Create → Read → Update → Delete**

It was developed to strengthen my understanding of **JavaScript, DOM manipulation, API handling, and frontend-backend communication**.

## ✨ Key Features

* ➕ Add new records
* 📋 View all records
* ✏️ Edit existing records
* 🗑️ Delete records
* 🔄 Dynamic data updates
* 📱 Responsive user interface
* ⚡ Simple and fast user experience
